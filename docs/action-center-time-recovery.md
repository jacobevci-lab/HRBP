# Action Center time decision recovery
Action Center time approvals/rejections use the shared bounded time receipt verifier. Queue metadata is projected through a fail-closed adapter, and a page-owned registry seals an entry before POST so filters or queue refresh cannot reopen an opposite decision while the result is unknown. Unknown/malformed/timeout/mismatched outcomes are never retried automatically. Notification acknowledgement is best-effort after a verified decision. Generic Action Center handlers explicitly exclude time metadata. Server authorization, relationship scope, schedule/integrity checks, serializable writes, audit and durable notifications remain authoritative. The registry is page-local, not cross-tab durable idempotency.
